# Student Management REST API

## Deskripsi

Aplikasi pengelolaan data siswa berbasis REST API yang terintegrasi dengan frontend menggunakan Fetch API.

## Teknologi

- Node.js
- Express.js
- MySQL
- HTML
- CSS
- JavaScript
- REST API
- Fetch API
- Git
- GitHub

## Data Siswa

- ID
- NIS
- Nama
- Kelas
- Jurusan
- Alamat

## Menjalankan Aplikasi

### Backend

Jalankan server dari folder project:

```bash
node server.js
